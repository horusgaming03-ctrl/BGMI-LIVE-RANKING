# Map assets

Bundled **SVG placeholders** are used until you add real in-game screenshots.

To use custom art:

1. Add `erangel.jpg` (etc.) here, or
2. Upload via **admin → Match cards → Custom map upload**, or
3. Set a URL in **Map image override**.

Supported maps: Erangel, Miramar, Rondo, Sanhok, Vikendi, Livik, Nusa.
